# Security and project data

Do not commit credentials, tokens, private URLs, confidential plant layouts, supplier intellectual property, personal data or restricted operating records. Keep the public example synthetic and separate from project-controlled information.

Report suspected code vulnerabilities privately to the repository owner using a private channel available on their GitHub profile. Do not disclose exploitable details or plant-sensitive information in public issues. Ordinary engineering/model limitations should be documented with reproducible non-sensitive cases.

The calculation program reads command-line values and writes local reports; it does not control equipment or connect to a plant system. Review code and input/output locations before integrating it into other workflows.
